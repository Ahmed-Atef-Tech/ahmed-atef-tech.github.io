# Ahmed Atef — Portfolio Website

A personal portfolio page built with pure HTML/CSS/JS.
Hosted via **GitHub Pages** at: `https://ahmed-atef-tech.github.io`

## Structure

```
portfolio-site/
├── index.html          # Main portfolio page
└── assets/
    ├── shutdown-timer-preview.png
    └── multi-researcher-preview.png
```

## How to Update

1. Edit `index.html` to add new apps
2. Add new screenshot to `assets/`
3. Push to GitHub — the site updates automatically
